Sites bloqués : récupérer les annonces — un lien de recherche direct et le code pour chaque site
Site1. Ouvrir la recherche2. Code à coller dans la console du site
Ces sites me bloquent : je n'ai pas pu ouvrir ces liens moi-même. Si l'un tombe sur une page vide, fais la recherche à la main sur le site.
  1. Clique Ouvrir la recherche (Paris, achat, hôtel particulier). Ajuste au besoin : 500 m² minimum, Neuilly.
  2. Clique Copier le code, puis sur le site : Cmd+Option+J → onglet Console → efface (Cmd+K) → colle (Cmd+V) → Entrée. La 1re ligne collée doit commencer par (function extraire. S'il refuse le collage : tape allow pasting, Entrée, recolle.
  3. Un message « X annonces copiées » s'affiche. Reviens ici et clique Coller des annonces (en haut). Recommence pour chaque page de résultats.
Plus simple encore : fais glisser Copier les annonces dans ta barre de favoris et clique-le sur le site, sans console. Ces annonces restent dans ce navigateur, pas dans le dépôt.
